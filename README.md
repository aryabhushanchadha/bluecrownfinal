# Blue Crown 👑

Premium cotton t-shirts e-commerce website for [cottonrus.ru](https://cottonrus.ru)

![Blue Crown](https://img.shields.io/badge/Blue%20Crown-Premium%20Cotton-3b6cf5)
![License](https://img.shields.io/badge/license-MIT-green)

## 🛍️ About

Blue Crown is a modern e-commerce website selling premium 180 g/m² cotton t-shirts. Features include:

- **Product Catalog** — White, Black, and Red classic t-shirts
- **Shopping Cart** — Add items, select sizes, adjust quantities
- **Telegram Ordering** — Direct checkout via [@bluecrownllc](https://t.me/bluecrownllc)
- **Wholesale Services** — DTF printing, screen printing, and embroidery for bulk orders
- **Responsive Design** — Works on all devices

## 🚀 Tech Stack

- **React 19** — UI framework
- **Vite** — Build tool
- **Tailwind CSS 4** — Styling
- **TypeScript** — Type safety
- **Lucide React** — Icons

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/blue-crown.git

# Navigate to project
cd blue-crown

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deployment

The production build outputs a single `dist/index.html` file that can be deployed to:

- **Netlify** — Drag & drop the `dist` folder
- **Vercel** — Import from GitHub
- **Any static hosting** — Upload `dist/index.html`
